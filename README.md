# 工作周记

一个 Windows 95 风格的网页版工作周记小工具，用表格记录每天各时间段的工作内容，并在每周末填写本周总结和下周安排计划。

## 使用方式

直接用浏览器打开 `index.html` 即可使用，无需安装依赖。

## 功能

- 自动按周生成 7 天记录，左侧显示“几月几号 星期几”。
- 每天按 08:00-09:00、09:00-12:00、12:00-14:00、14:00-18:00、18:00-19:00 分类填写工作内容。
- 支持本周总结和下周安排计划。
- 使用浏览器本地存储自动保存，可在左侧查看周记存档。
- 支持导出和导入 JSON 存档文件，方便长期备份。
